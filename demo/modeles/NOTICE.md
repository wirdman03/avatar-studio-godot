# Ari

Ari est un personnage fictif créé pour la démonstration d’Avatar Studio. La scène
`ari.tscn` et son catalogue `catalogue.json` sont mis à disposition sous
[CC0 1.0 Universal](CC0-1.0.txt). Le script `sources/generate_demo.gd`, qui génère
le modèle dans Godot, fait partie du code sous [licence MIT](../../LICENSE).
